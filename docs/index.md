# DSW translation automation

This tool connects Markdown translation contributions to official DSW Weblate.

Translators work in the [translation repository](https://github.com/ThreeMonth03/dsw-ui-locales-zh_Hant).
Maintainers use GitHub Actions to synchronize versions and submit reviewed batches.
